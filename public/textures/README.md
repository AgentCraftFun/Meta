# Textures

Drop these files here to enable the photoreal earth look. The app falls back to
procedurally generated textures if any are missing, so the scene never crashes.

Recommended assets (NASA Blue Marble + Visible Earth, public domain):

- `earth_day.jpg` — 8K daylight basemap
- `earth_normal.jpg` — 8K normal map derived from elevation
- `earth_specular.jpg` — water/land mask for ocean shine
- `clouds.png` — 8K cloud alpha (transparent PNG)

Sources:

- https://visibleearth.nasa.gov/collection/1484/blue-marble
- https://www.solarsystemscope.com/textures/ (CC-BY 4.0)
